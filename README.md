# MosMap

Веб-приложение для работы с геоаналитикой: просмотр, управление и анализ географических объектов на интерактивной карте.

## Технологии

| Область | Технология |
|---|---|
| Фреймворк | Next.js 15 (App Router) |
| UI | React 19, Tailwind CSS |
| Карта | Leaflet, React-Leaflet, React-Leaflet-Cluster |
| Серверный стейт | TanStack React Query |
| Клиентский стейт | Zustand |
| Формы | React Hook Form |
| HTTP-клиент | Axios |
| Архитектура | Feature-Sliced Design (FSD) |

## Запуск

```bash
npm install
npm run dev
```

Приложение доступно на [http://localhost:3000](http://localhost:3000).

## Функциональность

### Интерактивная карта

Основа приложения — карта на базе Leaflet. На карте отображаются:

- **Маркеры** объектов с иконками и кластеризацией (объекты группируются при отдалении)
- **Полигоны** — площадные объекты, нарисованные поверх карты
- **Маркер точки области** — показывает выбранное место на карте при клике вне объектов
- **Маркер нового объекта** — отображается при создании нового объекта

Клик по пустому месту карты открывает карточку с информацией о точке (адрес, координаты и т.д.). Клик по объекту открывает его карточку.

---

### Список объектов

Боковая панель со списком всех объектов карты. Использует виртуализацию (`@tanstack/react-virtual`) для плавной работы с большими списками. При клике на объект в списке — он выделяется на карте и открывается его карточка.

---

### Фильтры

Панель фильтров для поиска и сортировки объектов по различным параметрам. Поддерживаются фильтры типов:

- **Список** (выбор одного значения из набора)
- **Диапазон** (числовой диапазон min–max)
- **Карта** (множественный выбор категорий)

Параметры фильтров синхронизируются с URL-строкой (query params), что позволяет сохранять и передавать состояние фильтрации через ссылку.

---

### Карточка объекта

При выборе объекта открывается боковая панель с карточкой. Содержит:

- Название объекта
- Набор атрибутов (поля типа `input` и `select`)
- Панель действий (кнопки управления объектом)

**Панель действий** включает:

| Кнопка | Действие |
|---|---|
| Показать на карте | Центрирует карту на координатах объекта |
| Установка маркера | Удалить или переместить маркер объекта |
| Зона доступности | Показать организации в радиусе от объекта |

#### Редактирование объекта

Авторизованные пользователи видят форму редактирования с кнопками **Сохранить**, **Отменить**, **Удалить**. При попытке переключиться на другой объект с несохранёнными изменениями — показывается попап с предложением сохранить изменения.

---

### Установка маркера

Режим перемещения или удаления координат объекта на карте (доступен только авторизованным пользователям):

1. Нажать кнопку «Установка маркера» → выбрать действие: **Удалить** или **Переместить**
2. В режиме перемещения курсор становится крестиком, пользователь кликает по нужному месту карты
3. Правый клик завершает выбор позиции → появляется попап подтверждения
4. При подтверждении координаты объекта обновляются на сервере

При переключении на другой объект режим перемещения сбрасывается автоматически без сохранения.

---

### Зона доступности

По нажатию кнопки «Зона доступности» в карточке объекта открывается список организаций, расположенных в пешей доступности от объекта. Организации сгруппированы по типу, для каждой указано расстояние. Группы можно сворачивать/разворачивать.

---

### Создание объекта

Авторизованные пользователи могут создавать новые объекты. Форма создания открывается из панели опций. Поддерживается выбор координат кликом по карте. После сохранения объект появляется на карте и в списке.

---

### Окраска зон

Функционал визуализации: позволяет окрасить объекты на карте в разные цвета в зависимости от значения выбранного атрибута. Удобно для быстрого визуального анализа распределения показателей.

---

### Информация о точке

Клик по пустому месту карты открывает боковую панель «Информация по точке» с данными о выбранной географической точке (например, адрес, административная принадлежность).

---

### Импорт и экспорт

- **Импорт** — загрузка объектов из файла в базу данных карты
- **Экспорт** — выгрузка объектов карты в файл

---

### Аутентификация

Полный цикл управления учётной записью:

- Вход по e-mail и паролю
- Регистрация с подтверждением e-mail
- Восстановление и смена пароля

Авторизованные пользователи получают доступ к редактированию объектов, установке маркеров, созданию объектов и настройкам.

---

### Настройки

- **Настройки карты** (`/settings-map`) — конфигурация параметров отображения карты
- **Настройки базы данных** (`/settings-database`) — управление подключением к источнику данных

## Архитектура

Проект построен по методологии **Feature-Sliced Design (FSD)**:

```
src/
├── app/          # Next.js App Router: страницы, API-роуты, провайдеры
├── widgets/      # Крупные составные блоки UI (карта, панели, виджет зоны доступности)
├── features/     # Самодостаточные бизнес-фичи (фильтры, редактирование, авторизация)
├── entities/     # Бизнес-сущности (place, map) — хуки, стор, UI примитивы
└── shared/       # Переиспользуемые компоненты, хуки, утилиты, константы
```

### Ключевые сторы (Zustand)

| Стор | Назначение |
|---|---|
| `useTargetPlaceIdStore` | ID выбранного объекта |
| `useViewBlocksStore` | Текущий режим боковой панели (`filters`, `place-info`, `area-info`, `create-place`) |
| `useMoveMarkerStore` | Состояние режима перемещения маркера |
| `useViewAvailabilityZoneStore` | Видимость зоны доступности |
| `useCenterMapStore` | Центр карты |

### API-прокси

Все запросы к бэкенду проходят через Next.js API-роуты (`/api/*`), которые служат прокси к внешнему серверу. Это позволяет скрывать адрес бэкенда и управлять авторизационными заголовками на уровне сервера.
